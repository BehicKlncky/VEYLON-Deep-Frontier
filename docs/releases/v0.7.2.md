# VEYLON 0.7.2 — Death Ragdolls & Blood

Animals and people now fall as articulated bodies when killed. The killing
blow carries into the fall, and bodies collide with terrain, slide down slopes
and sink in water before coming to rest. Animal carcasses retain their landed
pose; people leave persistent, non-harvestable corpses that decay over time.

Blood bursts at the moment of death, drips from moving bodies and leaves a
stain where they settle. Harvesting waits for a body to land, with lodged
arrows preserved for recovery. Death rewards and reputation changes still
happen on the killing tick.

Existing saves remain compatible with binary save format v3. Body poses and
human corpses use an optional extension section; saving during a fall first
settles the body so it is preserved. Existing carcasses retain their old pose.

The feature includes deterministic physics, death-event, save-compatibility,
blood-budget and allocation tests, plus repeatable ragdoll capture scenes.
The Windows Java 25 release-candidate build passed all 704 tests across 105
classes with no failures or skipped tests, together with Javadoc validation
(`gradlew.bat build --rerun-tasks --no-daemon --console=plain`, 2026-09-18).
GPU/audio smoke tests and hardware performance benchmarks were not rerun as
part of this merge; platform packaging runs in the tag workflow.
See the [architecture notes](../ARCHITECTURE.md#death-ragdolls-and-blood-072)
and [QA guide](../DEVELOPING.md#death-ragdoll-qa-and-contributor-rules-072).

Pushing the v0.7.2 tag triggers the release workflow to build, validate and
publish Windows x64, macOS arm64 and macOS x64 archives with SHA256SUMS.txt.
