# VEYLON: Deep Frontier 0.3.1

Version 0.3.1 is a focused stability, refactoring and performance patch. It adds no
new content and does not change the save format or world generator.

## Highlights

- `Game` remains the high-level loop and simulation orchestrator, while headless
  player movement/voxel physics, medical treatment and gameplay action routing now
  have explicit systems and deterministic test boundaries.
- The normal per-frame targeting path uses caller-owned mutable DDA results. Independent
  buffers protect target and fluid queries; the immutable API remains compatible.
- One logical settlement theft can no longer apply duplicate reputation or alert effects.
  Bounded transfer identities make callback retries idempotent while ensuring distinct
  same-type stacks all update the settlement stock ledger.
- Path reconstruction fails safely if its defensive node cap cannot reach the start.
  NPCs never receive a truncated disconnected suffix.
- Exact-boundary ray starts now hit the adjacent voxel, settled-NPC perception honors
  its intended cadence, and players can step up one block but not two.
- Runtime light changes use point updates; chunk faces reuse scratch storage; projectiles
  reuse a strict bounded pool; OpenAL frame arrays are retained.

## Verification and coverage

The deterministic suite contains 223 tests, 63 more than 0.3.0. New coverage spans
movement/collision, raycasting, interaction ordering, theft transactions, path bounds,
fire, afflictions and treatment, water, temperature, shelter, plants, coordinate safety,
lighting, projectile reuse and AI perception cadence.

The final release gate passed `clean build`, an independent forced test rerun, the full
Windows `releaseArtifacts` packaging path and the 30-second fixed-seed OpenGL smoke
test. The smoke run met the 60 FPS gate, completed save/load, fire and fortress
approach, reported zero GL/KHR errors and kept every runtime collection inside its hard
limit.

## Compatibility

- Binary save version: **v3**, unchanged.
- Historical v0.2.0/v2 migration: retained and regression-tested.
- World generator: **version 3**, unchanged; seed output is not modified.
- Serialized enums: unchanged and append-only.
- OpenGL 3.3 Core, OpenAL, Java 25, LWJGL 3.3.6 and the dependency set are unchanged.

## Deferred work

- Bulk chunk generation/load still performs a complete light-list rebuild; replacing
  that safe bounded pass is not justified for this patch.
- The save extension section count and explosion block/chain limits remain explicit
  corruption/workload guards. Current writers use 7 of 256 save sections, and current
  maximum blast power cannot reach the 900-block destruction cap.
- Particles and entity visibility were already allocation-free at the reported sites;
  no replacement infrastructure was added.
- No allocation profiler or hands-on manual gameplay session was available.
