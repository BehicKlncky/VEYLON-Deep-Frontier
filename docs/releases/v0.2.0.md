## VEYLON: Deep Frontier 0.2.0

This release replaces the prototype presentation with a complete procedural
graphics pipeline and adds self-contained Windows and macOS packages.

### Downloads

| Platform | Asset |
| --- | --- |
| Windows 10/11 x64 | `veylon-0.2.0-windows-x64.zip` |
| macOS Apple Silicon | `veylon-0.2.0-macos-arm64.zip` |
| macOS Intel | `veylon-0.2.0-macos-x64.zip` |

Extract the matching archive, then launch `Veylon.exe` on Windows or
`Veylon.app` on macOS. A Java installation is not required for these packages.

The macOS applications are not yet Developer ID signed or notarized. Gatekeeper
may require explicit first-launch approval from **System Settings → Privacy &
Security**. Verify the downloaded archive against `SHA256SUMS.txt` before using
that override.

### Highlights

- Procedural 64×64 material system with biome/season variation and stable visual
  IDs.
- Forward PBR-lite terrain and entity rendering, PCF shadows, animated water,
  procedural sky, bloom, tonemapping, FXAA and gameplay-state post effects.
- Articulated models for creatures, NPC roles and first-person held items.
- Instanced particles, mining cracks, tracks, blood, beacon, fire and weather
  effects.
- Source Sans 3 UI, generated icons for all 70 items, and redesigned title,
  loading, HUD, options, death and victory presentation.
- Deterministic capture scenes, render diagnostics, automated save/load smoke
  testing and a configurable minimum-FPS release gate.
- Platform-aware LWJGL natives and self-contained packages for Windows x64,
  macOS arm64 and macOS x64.

### Compatibility

- Save format remains binary v2; serialized `BlockType` and `ItemType` order is
  unchanged from 0.1.0.
- Prototype save format v1 is not supported; start a new world.
- OpenGL 3.3 Core is required.

See `CHANGELOG.md` in the repository for the full change list and known
limitations.
