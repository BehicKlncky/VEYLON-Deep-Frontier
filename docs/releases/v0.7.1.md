# VEYLON 0.7.1 — Physical Rain

Rain now falls through the voxel world. Drops lean with smooth wind, strike roofs,
trees, terrain and water, and scatter into tiny droplets at contact. Looking out
from a shelter still shows the rain outside. Storms have more rain and stronger
lateral motion, while the particle-density setting reduces emission and spray.

The old screen-space rain overlay and preemptive ground splashes are removed.
Rain stays depth-tested in the existing two-pass particle renderer, with bounded
weather budgets that leave room for fire and combat effects. Snow retains its
previous behavior.

This is a visual change: wetness, weather probabilities, gameplay water, saves,
Survival and Creative rules are unchanged. Solid-block collision uses the same
voxel semantics as world collision; non-solid decorative shapes are not new
rain blockers. Water contact uses its rendered 0.88-block surface height.

See the [engineering validation record](../engineering/v0.7.1-validation.md) for
commands, measurements, capture coverage and platform scope. No release tag or
GitHub Release is published as part of this source update.
